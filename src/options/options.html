📋 Repository Structure

Each device profile writes to its own folder in your private repository:

bookmarks/{profile-folder}/bookmarks.json

The file contains your full bookmark tree preserving all folder hierarchy. Only written when bookmarks actually change.

Each change also saves a snapshot to history:

bookmarks/{profile-folder}/history/{timestamp}.json

An index of all snapshots is kept at:

bookmarks/{profile-folder}/history/index.json
